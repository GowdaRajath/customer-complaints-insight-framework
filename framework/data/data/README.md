# Synthetic Dataset Description

The dataset included in this directory is a **synthetic and anonymised sample dataset** created solely for demonstration purposes.

It does not contain:
- Real customer information
- Employer-specific data
- Personally identifiable information (PII)
- Proprietary operational details

The structure and values are designed to reflect realistic complaint scenarios commonly observed within regulated industries, such as insurance, in order to demonstrate analytical frameworks and methodologies.

This dataset is intended to support example analysis only.
